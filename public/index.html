INCOMING REQUESTS

n8n webhook

Import n8n/triage-workflow.json into n8n. Its authenticated webhook accepts request JSON, calls the FlowDesk REST API, and returns the classified result.

{ "title": "Login outage", "message": "Our team cannot sign in to the dashboard." }

Set an n8n webhook header credential and an HTTP Header Auth credential using Authorization: Bearer <APP_TOKEN>. Keep the token private.

OUTGOING RESULTS

Slack & Google Sheets

After you approve a request, FlowDesk sends its summary to Slack and adds a row to Google Sheets when those destinations and LIVE_DELIVERY=true are configured.

01Set SLACK_WEBHOOK_URL.
02Add Google service account credentials and the Sheet ID.
03Restart the server and confirm connection status here.
Unconfigured destinations are marked “preview only”; no external message or row is sent.
